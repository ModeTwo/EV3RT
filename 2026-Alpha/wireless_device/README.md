# 無線通信デバイス用 最適経路計算サーバー

このフォルダのソフトウェアは、操作台へ設置する無線通信デバイス（ノートPC等）そのものに配置して実行します。
走行体とはBluetooth PANまたはWi-Fiで双方向通信します。大会中に、別のPC・インターネット・クラウドへ接続する構成ではありません。

```text
走行体（Raspberry Pi）
  └─ Bluetooth PAN または Wi-Fi ─ 無線通信デバイス（ノートPC）
                                  ├─ UDPヒント受信
                                  ├─ A*最適経路計算
                                  └─ 3周分の戦略配列返送
```

## 役割分担

- 走行体（Raspberry Pi）
  - Webカメラでヒントカードを読む
  - ヒントカード2を4桁キーで復号する
  - ヒント1・2を無線通信デバイスへ送る
  - 返された`(絶対角度, 距離mm)`配列を機械走行する
- 無線通信デバイス（このサーバーを動かすPC）
  - ヒント形式を検証する
  - 赤→青→黄のゲート順を構成する
  - 他ゲートを障害物としてA*で短経路を探索する
  - 3周分の戦略配列を走行体へ返す

## 通信

走行体から次のJSON/UDPを受信します。

```json
{"type":"hint1","value":"25,35"}
{"type":"hint2","value":"53,54/12,22"}
```

両方が揃うと、送信元の走行体へ次の形式で返します。

```json
{
  "type": "route",
  "angle_type": "absolute",
  "laps": [
    {"segments": [[0.0, 300], [90.0, 200]]},
    {"segments": [[0.0, 300], [90.0, 200]]},
    {"segments": [[0.0, 300], [90.0, 200]]}
  ]
}
```

## 起動

`2026-Alpha`ディレクトリで実行します。

```powershell
python -m wireless_device.server `
  --bind 0.0.0.0 `
  --port 50000 `
  --allowed-robot 192.168.10.2
```

走行体側は以下のように無線通信デバイスのIPを指定します。

```powershell
python left_course_2026.py `
  --wireless-host 192.168.10.1 `
  --wireless-port 50000 `
  --route-listen-port 50001
```

大会会場ではWi-FiよりBluetoothが推奨されています。Bluetooth PANを作成した場合も、PAN内のIPアドレスを指定すれば同じUDPプログラムを使用できます。

## 必須調整

`planner_config.json`のゲート間隔、開始位置、終了位置は、公式の
`2026_competition_course_50pct_v0.3.pdf`を実寸へ2倍換算して設定しています。

- ゲート位置間隔: 250mm
- 座標原点: G1-5
- X正方向: G1からG5へ向かう右方向
- Y正方向: Gx-5の行からGx-1の行へ向かうコース上方向
- 開始位置: 上側赤ゾーン付近の青線中心 `(1178, 857)`
- 終了位置: 左側4色ライン上端の青い球中心 `(-148, 876)`

印刷・施工誤差と機体中心の置き方があるため、次の値は現地で最終確認してください。

- `start_mm`: ETラリー開始時の機体中心
- `finish_mm`: 最後に到達する青い球付近の機体中心
- `gate_approach_mm`: ゲート手前・通過後に確保する距離
- `obstacle_clearance_mm`: ゲートと機体回転中心の安全距離。現在は100mm
- `heading_sign`: 走行体ジャイロの正方向が右なら`1`、左なら`-1`

特に開始・終了位置は、カラーセンサー位置ではなく機体回転中心を基準に微調整してください。
ゲートポジション間隔が250mmのため、安全距離を125mm以上にすると隣接ゲート間の中心経路が幾何学的に閉じる配置があります。
現在の100mmは経路生成を成立させる暫定値です。機体回転中心から左右の最外端までを実測し、その値が100mmを超える場合は、
ゲート間を抜けない経路制約の追加を含めて再調整してください。

## PC単体テスト

```powershell
python -m unittest discover -s wireless_device -t . -v
```

このテストはヒント解析、経路計算、ローカルUDPでのヒント受信から経路返送までを実行します。走行体やモーターには接続しません。

## 規約上の注意

- 無線通信デバイスはCPU・メモリ・バッテリを内蔵し、30分以上外部電源なしで動作する必要があります。
- 自作無線通信デバイスは事前申請・承認が必要です。
- 競技中、無線通信デバイスから走行体以外の外部PCやインターネットへ接続しないでください。
- Bluetoothは車検前までにペアリングを完了してください。
- 実際の機器構成と通信I/Fを要求・システム分析・設計・制御モデルへ反映してください。
