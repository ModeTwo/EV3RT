## 前回までの方針と結果

- 80mm遅延・距離倍率0.75: 3番目が早く曲がり、内側のピン方向へ入った。
- 250mm遅延・距離倍率1.0: ピン方向への切込みはなくなったが、曲がる前に上側へ直進した。
- 175mm遅延・距離倍率1.0: 完走方向へ曲がったが、上側カーブでは黒線より外側を走った。

175mmで「曲がり始めない」状態は解消したが、黒線中心へ近づける意図に対しては遅延がまだ大きかった。

## 画像縮尺

ビューアで使用している公式PDFの換算値は0.7422056898mm/PDF point、背景基準は7738.58×5159.06 point、描画基準は1800×1201px。実走記入画像は2252×1366pxである。

- 横方向: 約2.55mm/px
- 縦方向: 約2.80mm/px

縦横で値が異なるのは、実走記入画像が描画基準と異なる縦横比へ拡大されているためである。

## 黒線との差

上側カーブのx=900～1180px付近を複数点で比較した。

- 80mm遅延時: 黒線より内側へ約85～110px
- 175mm遅延時: 黒線より外側へ約149～157px

符号付き画素差を80～175mmの間で線形補間すると、黒線中心付近になる遅延量は約113～119mmだった。赤線が手描きで線幅と位置に誤差があるため、1mm単位にはせず120mmを採用した。

ただし、80mm時は距離倍率0.75、175mm時は距離倍率1.0であり、比較には開始位置と旋回半径の両方の差が含まれる。このため120mmは縮尺を考慮した次回試験値であり、確定補正値ではない。今回以降は距離倍率1.0を固定するため、次の画像から開始遅延だけの効果を比較できる。
