# スタート～LAP 実走分析と次手 v9

対象画像は `ロボ経路/09121950.jpg`。赤線を実走軌跡として分析した。

## 前回の修正方針

3番目のカーブが内側へ切れ込み、中央寄りのコース外ピンへ衝突していた。そこで、3番目の距離倍率を0.75から1.0へ戻して旋回半径を広げ、旋回開始遅延を80mmから250mmへ増やした。

## 実際に得られた結果

- 内側のピンへ向かう軌跡は解消した。
- 3番目のカーブへ入る前の直線を長く進むようになった。
- ただし、曲がり始める前に上側のコース外へ直進した。

旋回半径を広げた方針は意図どおりに働いた。一方、開始位置は意図より遅くなった。

## 意図どおりでなかった理由

開始遅延を170mm増やした変更と、カーブ長を177.5mm増やした変更を同時に行ったため、どちらの効果がどの程度必要かを一回の走行で分離できなかった。今回の軌跡からは少なくとも250mmの開始遅延が過大だと分かる。

## 次の一手

旋回半径を広げる距離倍率1.0は維持する。開始遅延だけを、早過ぎた80mmと遅過ぎた250mmの中間である175mmへ変更する。

```python
start_lap_third_turn_distance_scale: float = 1.0
start_lap_third_turn_start_delay_mm: float = 175.0
```

次回は、3番目の旋回開始位置が上側の白コース内に収まり、中央のピン側へ切れ込まず、外側へ直進しないことを確認する。まだ開始が遅ければ25～50mm減らし、早ければ25～50mm増やす。距離倍率は開始位置が決まるまで変更しない。
