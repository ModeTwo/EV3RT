# スタート～LAP 後続カーブ距離調整 v6

最初のカーブは変更せず、それ以降の3カーブだけ、目標方位角が変化し終わるまでの走行距離を短くする。

## 初学者が変更する場所

`config.py` の次の値だけを変更する。

```python
start_lap_later_turn_distance_scale: float = 0.75
```

- `0.75`: 元の75%の距離で曲がり終える（今回の初期値）
- `0.85`: 今回より緩やかに曲がる
- `0.65`: 今回より早く曲がり終える
- `1.00`: 短縮しない

対象区間は `start_lap_calibration.py` の `LATER_TURN_RANGES_MM` にまとめてある。方位角そのものや直線区間の長さは変えず、カーブ内の距離軸だけを縮める。各カーブより後ろの距離も短縮量だけ前へ移動するため、青検知開始位置とLAP終了位置も同じ基準で自動補正される。

この補正を使うのは `start_lap_mode = 'profile'` の場合だけである。`legacy` では従来走行が選ばれる。
