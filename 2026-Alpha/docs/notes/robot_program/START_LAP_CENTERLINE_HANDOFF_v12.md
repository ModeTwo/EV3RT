# スタート～LAP 黒線中心軌道と最終直線引渡し v12

## 判定訂正

`09122024.jpg`では赤線が上端と左側で緑へ出ている。緑へ少しでも出た走行は失敗であり、「上側への直進が解消した」というv10の評価は撤回する。

## これまで意図どおりでなかった原因

元の`POINTS`は公式PDFの黒線中心から作った距離・方位角表だった。しかし、後続カーブを0.75倍へ圧縮し、2番目を60mm前倒し、3番目を最大250mm遅延させたことで、名目経路自体が黒線中心から外れた。方位角制御は与えられた名目経路を追うため、実機調整を重ねても黒線へ収束する保証がなかった。

## 修正方針

1. 車軸中心から最初のカーブまでの実測補正600mmは維持する。
2. 後続カーブ倍率をすべて1.0へ戻す。
3. 2番目の前倒しと3番目の遅延を0mmへ戻す。
4. `RunByGyro`は公式黒線中心のPOINTSを最終直線途中まで走る。
5. 最終直線途中から`TraceLine`へ切り替え、黒線へ実測収束して青LAPへ渡す。

## 切替距離の計算

元POINTSの最終カーブ終了は4475mm、LAPゲートは5511.716628mm。最初の直線を500mmから600mmへ補正するため、500mm以降は100mm加算される。

- 最終直線開始: 4475 + 100 = 4575mm
- LAPゲート: 5511.716628 + 100 = 5611.716628mm
- 最終直線中間: (4575 + 5611.716628) / 2 = 5093.358314mm
- 設定値: 5100mm

## 次回の合格条件

- RunByGyro区間で赤線が一度も緑へ出ない。
- 最終直線でカラーセンサーが黒線を捕捉できる位置からTraceLineが始まる。
- 切替後に蛇行せず、黒線上へ収束する。
- 青LAP検出で次工程へ渡る。

RunByGyroは黒線の位置を直接観測しないため、名目軌道を黒線中心へ戻しても実走が必ず中心線と一致するとは限らない。最終直線のTraceLine切替で、蓄積した横ずれを実測して解消する。
