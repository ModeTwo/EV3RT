# ボトルデリバリー → ET相撲 試験

`--mission bottle-sumo --bottle-color red`（blue/yellowも可）で、Hint2後の配置ラインにボトルを保持している状態から、色別配置、赤→白検知または代替距離、カーブ、ET相撲、終了停止を実行する。最初のボトル取得、TO、ETラリーは含まない。左右は既存の `--course` で指定する。省略時は起動前に色を入力する。ジャイロ登録、タッチ開始、カメラ、録画はalphaが管理する。

カーブ後、録画を準備しながら停止せず1000mm/PWM80の相撲直進を開始し、その後既存の画像正対、捕捉、押し出しと後退を行う。捕捉後の押し出し距離はユーザー指定1000mm。録画の開始失敗・5秒以上の未準備など既存のエラー時には停止する。録画が準備できるまで走行を継続するので、直進中の一部の映像や検出は欠け得る。物理条件に対する距離・姿勢・捕捉の妥当性、録画準備時間は実測していない。

通しの競技順はLAP後にボトルデリバリー、相撲、ETラリーの順。相撲後にETラリーを有効にした場合、位置・方位が未測定のため既存の未実装移動が停止してFAILUREを返す。ラリー開始位置に到達する経路は実装されていない。

PCでは両コース・3色のツリー構築、直進1000mmと押し出し1000mmの設定、カーブ直後の無停止、録画エラー時の停止を模擬確認。`check_sumo_align.py` 全体は変更前から2項目が失敗。Pi転送・実走は未実施。赤白検知の代替距離は各色1回のログからの暫定値。既存の `phases/et_sumo_after_delivery.py` にあった未コミット変更は保持した。
