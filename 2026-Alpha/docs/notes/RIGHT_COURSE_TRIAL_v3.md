実機報告に対応した試験値です。①～③の原因・最適値はログと実走で確認が必要です。
共通20ms周期、経路の目標角度、Hint2の接近距離・角度は維持しました。

## 変更内容

|問題|変更|元へ戻す・追加調整する場所|
|---|---|---|
|①ジャイロ直進が左へずれる|rightのRE開始～LAPの5区間だけ、前進ジャイロ走行で左PWM+2、右PWM-2。小数切捨てを丸めへ変更し、出力を±100へ制限。目標角度・実角度・PID出力・左右PWMを毎秒記録|`right_course_tuning.py`の`RIGHT_GYRO_TRIM_PWM`。0で無効。右へずれたら減らす|
|②LAPカーブの首振り|rightのlap2_2だけPWM60→55、P .55→.40、D .08→.02、輝度LPF6Hzを追加|同ファイルの`RIGHT_LAP_CURVE_*`。I値と距離2460mmは維持|
|③AT終了位置が手前|rightのみ基準460mmへ100mmを追加し560mmへ延長|`RIGHT_AT_TRANSFER_EXTRA_MM`。基準はIntegrationSettings.at_to_transfer_trace_mm|
|④Hint2検証時間|Hint2読取は時間無制限、制動を保持し2秒間隔で診断ログ|IntegrationSettings.hint2_timeout_sec=None。秒数を入れると制限を復活|

①の固定PWM補正は左右駆動差を仮定した暫定値です。ジャイロのゼロ点ずれ、タイヤの滑り、低いゲイン等の原因を確定したものではありません。
対象はユーザーが特定したRE開始～LAPの5区間だけです。TO・ET相撲のジャイロ走行、旋回、ライントレース、ATの固定PWM直進・後退には適用しません。
TOの一部直進では元の非常に低いP値0.0001が残っています。対象区間をログから特定してゲイン変更を判断します。
leftの固定補正、LAPカーブ設定、AT距離は維持します。共通RunByGyroの出力丸め・制限と診断ログは両コースに適用します。

## Hint2の検証

```text
python alpha.py right
```

Hint2読取位置で止まり、読めるまで待ちます。終了操作はCtrl+Cです。
Hint1の20秒上限と、走行・旋回の30秒上限は維持しています。カメラ・復号処理自体の異常はエラー終了します。

`HINT2_WAIT`ログの意味：

- `capture_frame`：カメラ取得フレーム。増えなければ撮影側を確認。
- `decoded_frame`：最後に復号できたフレーム。-1は有効な読取結果なし。
- `reason=no_decode`：文字列が未取得。
- `reason=same_as_hint1`：Hint1と同じ内容のためHint2として受理していない。
- `reason=stale_session`：今回の読取ではない結果。
- `detecting`：復号処理中か、`corners`：QR位置候補があるか。表示は診断時点の参考値。

Hint2の停止位置・正対角度は原因が未確定なので変更していません。カメラ映像とこのログで切り分けます。
