# ライン取得・旋回停止確認 v5

## 適用
right / left共通、非B走行体。周期は従来どおりrobot_program/timing.pyの20ms。

REのジャイロ5区間後、従来の100mmトレースをAcquireLineに置換。PWM25でライン端を追従し、HSV V=65±12が0.10秒継続、かつ100mm以上進んだ場合だけLAPカーブへ移る。250mm到達または5秒経過で未取得ならFAILURE・制動停止し、次へ進まない。これは明度による取得判定であり、ライン形状や物体識別ではない。明度65に近い別の面を区別できないため実機で閾値確認が必要。

取得が100mmを超える場合、その超過分だけ後続への引渡し位置も変わる。LINE_ACQUIREログのdistance/Vで切替位置を確認。曲線ゲイン・右RE固定補正等の前回値は変更していない。取得後の曲線追従不足まで解消を保証する変更ではない。

TOの全to_turn（局所90度・0度、相対±25度）はSettledSpinを使用。AT終了時の角度基準は維持。残り30度以内はPWM上限を60から18へ近づけ、従来の最低55を解除。誤差2度未満でブレーキし、0.30秒間その範囲内かつ基準からの変化1度以内を確認して成功。範囲外へ行き過ぎた場合は低速で再補正。目標は再補正時にも再設定しない。30秒の移動タイムアウトと中断時制動を維持。TO以外のSpinAroundは従来動作。

調整値はrobot_program/motion_tuning.py。18PWMで回らない場合はTURN_NEAR_PWMを実機に合わせて調整。値は実機未確定。TURNログで目標・現在角・誤差・停止確認中かを記録する。センサーのドリフトや角度倍率が異常な場合、この制御だけでは物理角度を保証できない。

Ctrl+C修正版alpha.py、Hint2無期限読取を保持。原本単体プログラムは変更なし。
