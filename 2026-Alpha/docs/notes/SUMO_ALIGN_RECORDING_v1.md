# 正対動作の動画・フレームCSV記録 v1

alpha.pyのsumo-alignミッションで既定有効。起動コマンドは同じ。

```sh
python3 alpha.py left --mission sumo-align --sumo-distance-mm 1000 --sumo-power 80 --no-preview
```

録画ファイルが開けるまで停止して待ち（上限5秒）、その後に指定距離の原点を設定して直進する。初期化・タッチ開始・制御周期は従来alphaの処理。保存先はスクリプト位置から解決するため、PC固有パスに依存しない。

## 保存先と内容

2026-Alpha/sumo_align_runs/。Piの標準配置なら/home/pi/EV3RT/2026-Alpha/sumo_align_runs/。

1実行でUTC時刻＋IDを共通名とする4ファイルを生成する。

- `*_raw.avi`：未加工のカメラ画像。通常640x480。後から同じ検出器で再解析できる。
- `*_detected.avi`：中央16:9を320x180へ縮小した検出画像。候補枠・探索帯に加え、状態・フレームID・経過秒を表示。
- `*_frames.csv`：保存した各フレームのID、取得時刻、距離、ジャイロ、制御状態、セッション、候補の有無、確定状態、位置・面積、探索帯、最後の制御側観測判定を記録。
- `*_summary.json`：SUCCESS/FAILURE/INTERRUPTED/RECORDING_ERROR、理由、保存フレーム数、キューから落とした枚数、観測・確定枚数、状態ごとの枚数、実記録fps、出力先、書込エラー。

直進前のRECORD_START、DRIVE、SETTLE、OBSERVE、TURNの画像を同じ動画へ保存する。観測セッションを切り替えても録画は継続する。正常終了・検出タイムアウトでは、モーター停止後に最大5秒、記録キューの終了を待ってからミッションを終了する。Ctrl+Cでも既存停止経路から録画終了を要求し、カメラ終了時に閉じる。電源断・強制kill時のファイル完成は保証しない。

`--no-preview`でも保存する。MJPG/AVIの再生fps設定は30だが、実際の取得間隔とは別。実時間はCSVのcapture_monotonic_sec・elapsed_secを使う。ホストread終了時刻であり、カメラの露光時刻ではない。センサー値は原則フレーム取得直後の値で、モード移行時など取得情報がない場合はrecord-submitと明記する。

## 負荷と失敗時

既存カメラスレッドで1回だけ取得した画像を、最大8枚のキューで別の保存スレッドへ渡す。制御周期ではファイル書込やエンコード待ちをしない。保存が追いつかない場合は画像を落としてqueue_droppedへ数える。CSVと2本の動画は受理した同じフレーム順で保存し、フレームIDの飛びから欠落を確認できる。Piでの負荷・実fpsは要確認。

録画開始失敗・書込エラーではその理由をログへ出して停止する。検出未確定・候補なし等のOBSERVE診断ログは最大約1秒に1回出し、各フレームの詳細はCSVへ残す。summaryのwriter_error、終了ログのfinished、frames、droppedも確認する。

## 2026-10-28 第1段階：対象追跡と評価用計測

起動方法・保存先は従来どおり。alpha.pyの初期化・タッチ開始・規定距離直進・既存旋回・停止の処理順序は維持する。今回の範囲は認識と計測であり、旋回中の画像制動、行き過ぎ後の縮小補正、停止位置予測は未実装。

### 候補選択と履歴

全輪郭へ面積150以上・高さ12以上・幅176以下・縦横比1.5以下・充填率0.45以上を適用してから選択。S<=120/V<=60のHSV候補と、V<=60のみの候補を併用する。遠方ではHSV候補を優先し、履歴と整合する、黒い小片を包含するV領域へ移行できるようにする。初期獲得時は左右端で切れた領域を採用しないが、獲得済み対象が端へ移動した場合の追跡は許す。上端を一律に除外する処理は入れない。

新しい候補は位置・大きさ・撮影時方位との整合で照合する。ジャイロ予測は既存pixel_bearingの逆式で、未校正という制約は残る。履歴は最大12候補、最終検出から0.5秒超・距離差180mm超などで破棄。見失った画像はcandidate=0/confirmed=0とし、予測枠のみで検出を捏造しない。追跡IDはこの仮説の識別子であり、正しいボトルという保証ではない。

同じミッション内の新しい観測セッションでは履歴を引き継ぎ、confirmedのみリセットする。新セッションの異なる2画像で確認してから採用する。セッション番号が古い画像は、追跡器の更新・観測の公開とも拒否する。ミッション開始時の通常の読み出しは履歴を初期化する。IDは検出器のインスタンス内で単調増加し、録画・セッション番号と合わせて解釈する。

ROIは候補選択の優先範囲として使い、輪郭を範囲境界で切らない。現段階は全画像でマスクを処理しているため、Eの計算時間短縮を実装したとは扱わない。

### CSV追加列の読み方

- track_id/track_status：同一対象仮説と確認状態。history_length/history_expired、association_dx/dyで照合・破棄を診断。
- mask_policy/mask_source：使用方針と採用マスク。hsv_candidate_count/value_candidate_countは各マスクの候補数で、同じ物体の重複を含む。
- detector_started_monotonic_sec/observation_ready_monotonic_sec/detector_duration_ms/capture_to_ready_ms：検出処理と公開までの遅延。撮影時刻は既存のホスト読み取り完了時刻で、露光時刻ではない。
- selected_frame_id/selected_capture_monotonic_sec/observation_selected_monotonic_sec/selected_observation_age_ms：制御で最後に採用した画像と、その採用時の古さ。各行の現在画像と同一とは限らない。
- sampled_angular_velocity_deg_s：録画用テレメトリ取得時のジャイロ差分推定。独立した角速度センサー値ではない。control_sample_monotonic_secはそのサンプル時刻。
- phase_entered_monotonic_sec/brake_command_monotonic_sec：工程開始と最新ブレーキ指令時刻。物理的な停止完了時刻ではない。
- requested_turn_bearing_deg/requested_turn_step_deg/measured_heading_error_deg/camera_error_px：最後の旋回判断を記録。
- turn_stage/turn_main_power_setting：既存旋回の段階と主出力設定。各周期の実モーター指令値・実測出力の記録ではない。

録画用の制御スナップショットとカメラの姿勢サンプルは時刻が異なるため、それぞれのタイムスタンプを使う。ブレーキ指令から完全停止までの時間は、映像とジャイロ時系列を合わせて評価する。
