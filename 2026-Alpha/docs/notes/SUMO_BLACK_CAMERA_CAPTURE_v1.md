# ET相撲 黒ボトル撮影・検出確認 v1

## 目的

USBカメラの画像を撮影し、ET相撲の `py_etrobo_util/video.py` と同じ黒HSV条件・輪郭条件でどの候補が選ばれるかを確認します。走行モーター、アーム、ETRoboセンサーは初期化しません。

## 実行

2026-Alphaのルートで実行します。

```console
python sumo_black_camera_capture.py
```

カメラ番号を変える場合は `--camera 1`、保存先を変える場合は `--output-dir ./captures/test1` を指定します。初期カメラ番号は0、希望解像度は640×480です。

## 操作と保存ファイル

- `S`：押した時点の画像を保存
- `Q` または `Esc`：終了
- `Ctrl+C`：端末から終了

既定ではリポジトリルートの `sumo_black_captures/` に同一時刻印で3枚保存します。

- `*_raw.png`：カメラから得た元画像
- `*_detector.png`：実行コードと同じ中央16:9切出し、320×180画像と候補枠
- `*_mask.png`：HSV閾値通過画素を白で表示したopen/close後のマスク

黄色枠は、面積150px以上、幅176px以下、縦横比4以下、充填率0.45以上を通過した最大面積輪郭です。マスクの白領域すべてが最終候補ではありません。

## 使用条件

`py_etrobo_util/video.py` の固定HSV範囲 H=0..179、S=0..120、V=0..60 と同じ判定です。位置ごとの相対比較、適応閾値、HSV移動平均は使いません。輪郭の形状条件も同ファイルに合わせています。

## 制約

実カメラで撮影し、照明や露出を変えて判定を確認してください。画面上に候補枠が出たことは、実走で確実にボトルを捕捉できる証拠ではありません。

## cv2 が見つからない場合

このスクリプトは py_etrobo_util/video.py と同じく、CPythonでは /usr/lib/python3/dist-packages を検索パスへ追加します。まず通常の python で再実行してください。まだ ModuleNotFoundError になる場合は、PiへOpenCVシステムパッケージが入っていません。Pi OSのAPTで python3-opencv を導入し、走行プログラムと同じCPythonで起動してください。競技用のvenvを使っている場合、そのPythonからシステムパッケージが見える設定かも確認してください。
