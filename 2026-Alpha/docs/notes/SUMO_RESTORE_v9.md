# ET相撲デグレ修復 v9

## 修復内容

復元処理でET相撲が「10度刻み停止探索・再探索1回・PWM 40台」へ戻っていたため、次を復元しました。

- 中心±60度の連続距離走査
- 20ms間隔で距離値と実ジャイロ方位を記録
- 候補方向へ正対後、停止して100ms間隔の有効値3回を確認
- 未検出時に100→70→50mmと最大3回接近して再探索
- ET相撲のモーター出力設定をすべて50以上
- ET相撲単体実行時のカメラ撮影・画像処理・プレビュー停止

## タイムアウト対策

従来の連続走査は、PWM50のまま目標角度±3度へ収束するまで待っていました。目標を飛び越すと往復し続け、距離値が`valid=True`でも候補選択へ進まず8秒で停止していました。

v9では既存`SpinAround`を旋回出力に使用したまま、外側端から内側端までの累積走査角が120度へ達した時点で成功にします。0度／360度境界とRight／Leftの鏡像を正規化方位で処理し、逆方向へ戻った角度は進捗から差し引きます。8秒タイムアウトはジャイロ停止・駆動停止に対する安全上限として残します。

ログには開始中心、外側端、内側端、現在方位、累積走査角、サンプル数、候補数、完了理由を出します。

## 実行

```sh
python alpha.py right --mission sumo
python alpha.py left --mission sumo
```

相撲単体ではカメラを生成しません。キャリブレーション、タッチスタート、カラー・距離・ジャイロセンサー処理は実行します。

## 実機で確認する項目

1. `continuous scan start`に中心・外側・内側角が出る。
2. `swept`が概ね0から120へ増加する。
3. `continuous scan complete reason=angle-crossed`または`target-tolerance`へ進む。
4. `select ... sumo sonar result`で候補が選択される。
5. 正対停止後に`stationary sonar candidate confirmed`が出る。
6. 未検出時だけ100、70、50mmの順で接近する。

`raw=108 valid=True`は距離検知成功です。候補選択へ進まない場合は、走査完了条件または方位進捗の問題としてログを確認します。全方向で距離差がほとんどない場合は、ゲート・床・機体部品等の固定反射を次段階で切り分けます。
